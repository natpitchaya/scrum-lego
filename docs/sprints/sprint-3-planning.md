# Sprint 3 Planning

**Sprint Goal:** Deliver a functional end-to-end event browsing experience, including:
*   A working events feed populated from real sources
*   Basic filtering/search
*   A stable production deployment
*   Initial backend architecture to support future personalization features

## Backlog Items Committed
The team has committed to the following user stories to achieve the MVP goal:

### Backend & Data
*   **Event Source API Integration (8 pts):** Implement backend ingestion, cleaning, and normalization of Yale + New Haven event feeds.
*   **Unified Event Feed (5 pts):** Deliver a consolidated event list rendered on the frontend.

### Frontend & UI
*   **Event Card Display (3 pts):** Build UI components showing event title, time, host, and source link.
*   **Responsive Web UI (3 pts):** Optimize layout for mobile and desktop screens.
*   **"More Info" External Link (2 pts):** Link each event card to its original webpage.

### Features
*   **Keyword Search (5 pts):** Implement full-text search allowing users to filter events by keywords.
*   **Filter by Date (3 pts):** Add predefined date-range filters ("Today / This Week").
*   **Add to Calendar (4 pts):** Enable Google Calendar, Outlook, and .ics file export.

### Planned but at Risk (Gap Analysis)
*   User Accounts / Authentication
*   Non-Yale New Haven Event Sources
*   Advanced Filtering Metadata
