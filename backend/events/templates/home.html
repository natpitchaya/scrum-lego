🎓 Yale Events Aggregator

Welcome! This application aggregates events from multiple Yale websites into a single API.

Sources: Yale School of Management (SOM) and Yale School of Public Health (YSPH)

📡 API Endpoints

All Events

Get all aggregated events from both sources

/api/events/
View All Events

Filter by Source

Get events from a specific source

/api/events/?source=SOM
View SOM Events
/api/events/?source=YSPH
View YSPH Events

Pagination

Use limit and offset parameters for pagination

/api/events/?limit=10&offset=0
View First 10 Events

🔧 Admin Panel

Access the Django admin interface to manage events

/admin/
Go to Admin
